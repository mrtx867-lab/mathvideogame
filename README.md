# Juegos matemáticos estilo Windows

Escape rooms matemáticos para jugar en el navegador, con estética retro de Windows. Se recomienda usar audífonos y tener un cuaderno a mano.

| Juego | Curso | Contenidos | Carpeta |
|---|---|---|---|
| **Enigma 95** | IV medio | Geometría, probabilidad, estadística, conteo | `index.html` (raíz) |
| **Virus 98** | IV medio (PAES M1/M2) | Números, álgebra, ecuaciones y sistemas, potencias, raíces y logaritmos, funciones | `virus98/` |
| **Virus 98 Jr.** | 7° básico | Números enteros, expresiones algebraicas, ecuaciones, fracciones y decimales, porcentajes y proporcionalidad | `virus98jr/` |

## Virus 98 y Virus 98 Jr.

El virus CIH.EXE infectó un computador con Windows 98 y Grace Hopper te guía para eliminarlo. Recorres un laberinto 3D cuyos muros son ventanas de Windows, resuelves 6 salas tipo Jeopardy (3 respuestas correctas por sala para ganar un disquete), superas 3 minijuegos de teclado (Ritmo de signos, Invasores algebraicos y Escalera) y al final instalas el antivirus con el código de los disquetes y derrotas al virus en un combate de cálculo rápido.

Para jugar, abre `virus98/index.html` o `virus98jr/index.html` (o su enlace de GitHub Pages).
