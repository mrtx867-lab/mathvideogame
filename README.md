# Enigma 95

Escape room matemático con estética Windows 95: laberinto 3D, salas tipo Jeopardy, KenKen, lluvia de cálculo mental, pasillo de luz roja / luz verde y una máquina Enigma para descifrar el mensaje final.

Se juega en el navegador abriendo `index.html` (o el enlace de GitHub Pages). Se recomienda usar audífonos y tener un cuaderno a mano para el desafío final.
